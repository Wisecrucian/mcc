# Changelog - Новые возможности

## Версия 2.0 - Настройка команды и множественные порты

### 🎯 Ключевые изменения

#### 1. Редактирование базовой команды
- **Настройки приложения**: Добавлена кнопка настроек (⚙️) в хедере
- **Кастомная команда**: Можно изменить команду для port forwarding
- **Формат команды**: `{команда} hostname:portfrom -p portto`
- **Пример**: `/usr/local/bin/mcc tp-port-forward db.example.com:5432 -p 5432`
- **По умолчанию**: `/usr/local/bin/mcc tp-port-forward`

#### 2. Множественные порты для одного хоста
- **Несколько портов на хост**: Каждый хост теперь может иметь несколько port mappings
- **Независимые процессы**: Каждый порт запускается как отдельный процесс
- **Визуализация**: Порты отображаются под хостом в виде тегов (например, `5432→5432`, `8080→80`)
- **Счетчик портов**: Показывается количество настроенных портов для каждого хоста

### 📝 Новые модели

#### PortMapping
```swift
struct PortMapping {
    let id: UUID
    var fromPort: Int  // Порт источника
    var toPort: Int    // Целевой порт
}
```

#### Обновленный Host
```swift
struct Host {
    let id: UUID
    var name: String
    var hostname: String
    var ports: [PortMapping]  // Массив портов
}
```

### 🎨 UI изменения

#### Добавление хоста
- **Секция портов**: Отдельная секция для управления портами
- **Добавление портов**: Поля "From" и "To" с кнопкой добавления
- **Список портов**: Scrollable список с возможностью удаления

- **Управление портами**: Те же возможности, что и при добавлении
- **Обновление в реальном времени**: Изменения применяются немедленно

#### Отображение хоста
- **Компактный вид**: Порты показаны под основной информацией
- **Цветовое кодирование**: Теги портов с синим фоном
- **Моноширинный шрифт**: Для четкого отображения номеров портов

### ⚙️ Settings View (новый)
- **Настройка команды**: Текстовое поле для ввода базовой команды
- **Пример использования**: Динамический пример с текущей командой
- **Сброс по умолчанию**: Кнопка возврата к дефолтной команде
- **Сохранение**: Команда сохраняется в UserDefaults

### 🔧 Технические изменения

#### ProcessService
- **Парсинг команды**: Автоматический разбор команды на executable и аргументы
- **Множественные процессы**: Управление отдельным процессом для каждого порта
- **Уникальные ID**: Генерация детерминистических UUID для процессов портов

#### AppViewModel
- **Агрегация состояний**: Host state рассчитывается на основе состояний всех портов
- **Логирование**: Улучшенное логирование с информацией о количестве портов
- **Graceful shutdown**: Корректная остановка всех процессов при удалении хоста

### 📊 Примеры использования

#### Настройка команды
1. Нажмите кнопку ⚙️ в хедере
2. Введите свою команду (например, `/opt/homebrew/bin/mcc tp-port-forward`)
3. Нажмите "Save"

#### Добавление хоста с несколькими портами
1. Добавьте новый хост
2. Введите имя и hostname
3. Добавьте порты:
   - `5432 → 5432` (PostgreSQL)
   - `6379 → 6379` (Redis)
   - `27017 → 27017` (MongoDB)
4. Нажмите "Add"

#### Результат
При запуске хоста будут созданы 3 отдельных процесса:
```bash
{command} hostname:5432 -p 5432
{command} hostname:6379 -p 6379
{command} hostname:27017 -p 27017
```

### 🐛 Миграция данных
Приложение автоматически добавит пустой массив портов к существующим хостам.
Для корректной работы необходимо:
1. Отредактировать существующие хосты
2. Добавить необходимые порты

### 💡 Рекомендации
- Используйте понятные имена для портов в логах
- Для production окружений рекомендуется настроить кастомную команду
- Проверяйте логи каждого порта отдельно при возникновении проблем
