# Руководство пользователя MCCPortForwarder

## Установка

### Шаг 1: Получите приложение
Скачайте файл `MCCPortForwarder.zip`

### Шаг 2: Распакуйте
Двойной клик по `MCCPortForwarder.zip` → появится `MCCPortForwarder.app`

### Шаг 3: Установите
Перетащите `MCCPortForwarder.app` в папку `/Applications/`

### Шаг 4: Первый запуск

#### Вариант A: Через Spotlight
1. Нажмите `Cmd + Space`
2. Введите "MCCPortForwarder"
3. Нажмите Enter

#### Вариант B: Через Applications
1. Откройте Finder → Applications
2. Найдите MCCPortForwarder
3. Двойной клик

### Возможная проблема при первом запуске

macOS может показать:
```
"MCCPortForwarder.app" cannot be opened because it is from an unidentified developer
```

**Решение:**
1. Откройте **System Settings** (Системные настройки)
2. Перейдите в **Privacy & Security** (Конфиденциальность и безопасность)
3. Прокрутите вниз до раздела "Security" (Безопасность)
4. Нажмите **"Open Anyway"** (Открыть в любом случае)
5. Подтвердите

## Использование

### Приложение в статус-баре
После запуска MCCPortForwarder появится иконка в статус-баре (верхний правый угол экрана).

### Открытие меню
Кликните по иконке в статус-баре.

## Основные операции

### 1. Добавить сервис
1. Нажмите кнопку `➕` в правом верхнем углу
2. Введите название (например, "Production DB")
3. Нажмите "Create"

### 2. Добавить хост в сервис
1. Разверните сервис (кликните на `▸`)
2. Нажмите кнопку "Add Host"
3. Заполните:
   - **Display Name**: например, "PostgreSQL"
   - **Hostname**: например, "db.production.com"
   - **Ports**: добавьте маппинги портов
     - From: `5432`
     - To: `5432`
     - Нажмите `➕` для добавления
4. Нажмите "Add"

### 3. Добавить несколько портов
При создании/редактировании хоста:
```
From: 5432  →  To: 5432   ➕   (PostgreSQL)
From: 6379  →  To: 6379   ➕   (Redis)
From: 8080  →  To: 80     ➕   (HTTP)
```

Каждый порт запускается отдельным процессом.

### 4. Запустить подключение

**Запустить один хост:**
- Нажмите зелёную кнопку ▶️ рядом с хостом

**Запустить все хосты сервиса:**
- Нажмите кнопку "Start" рядом с названием сервиса

**Запустить всё:**
- Нажмите "🚀 Start All" внизу

### 5. Остановить подключение

**Остановить один хост:**
- Нажмите красную кнопку ⏹ рядом с хостом

**Остановить сервис:**
- Нажмите кнопку "Stop" рядом с названием сервиса

**Остановить всё:**
- Нажмите "🛑 Stop All" внизу

### 6. Просмотр логов
1. Найдите нужный хост
2. Нажмите кнопку 🔍 (лупа)
3. Откроется окно с логами в реальном времени

**В окне логов:**
- ✅ Зелёный текст: успешные операции
- ❌ Красный текст: ошибки
- Toggle "Auto-scroll": автопрокрутка
- "Clear Logs": очистить логи
- "Done": закрыть окно

### 7. Редактирование

**Редактировать сервис:**
1. Нажмите ✏️ рядом с названием сервиса
2. Измените название
3. Нажмите "Save"

**Редактировать хост:**
1. Нажмите ✏️ рядом с хостом
2. Измените название, hostname или порты
3. Нажмите "Save"

### 8. Удаление

**Удалить хост:**
- Нажмите 🗑 рядом с хостом

**Удалить сервис:**
- Нажмите 🗑 рядом с сервисом
- Удалятся все вложенные хосты и подсервисы

### 9. Иерархия сервисов

Можно создавать вложенные сервисы:
```
▸ Production
  ▸ Databases
    🟢 PostgreSQL (5432→5432)
    🟢 Redis (6379→6379)
  ▸ Web Services
    🟢 API (8080→80)
```

Для создания подсервиса:
1. Разверните родительский сервис
2. Нажмите "Add Sub-Service"
3. Введите название

### 10. Настройки команды

**Изменить базовую команду:**
1. Нажмите ⚙️ (шестерёнка) в правом верхнем углу
2. Введите свою команду в поле "Base Command"
   - По умолчанию: `/usr/local/bin/mcc tp-port-forward`
   - Можно изменить на: `/opt/homebrew/bin/mcc tp-port-forward`
3. Нажмите "Save"

**Сброс к умолчаниям:**
- Нажмите "Reset to Default" в настройках

## Требования

### Обязательные
- **macOS**: 13.0 (Ventura) или новее
- **CLI команда**: Должна быть установлена команда `mcc` (или другая настроенная)

### Проверка установки CLI
```bash
which mcc
# Должно вывести: /usr/local/bin/mcc или /opt/homebrew/bin/mcc
```

Если команда не найдена:
1. Установите необходимый CLI
2. Или измените команду в настройках приложения (⚙️)

## Хранение данных

Все настройки хранятся локально в:
```
~/Library/Preferences/com.yourcompany.MCCPortForwarder.plist
```

### Резервное копирование
```bash
cp ~/Library/Preferences/com.yourcompany.MCCPortForwarder.plist ~/Desktop/mcc-backup.plist
```

### Восстановление
```bash
cp ~/Desktop/mcc-backup.plist ~/Library/Preferences/com.yourcompany.MCCPortForwarder.plist
```

## Удаление приложения

1. Закройте приложение (кликните на иконку → Quit)
2. Удалите из Applications:
   ```bash
   rm -rf /Applications/MCCPortForwarder.app
   ```
3. (Опционально) Удалите настройки:
   ```bash
   rm ~/Library/Preferences/com.yourcompany.MCCPortForwarder.plist
   ```

## Горячие клавиши

- `Cmd + Q`: Закрыть приложение (когда окно открыто)
- `Esc`: Закрыть окно настроек/редактирования

## Troubleshooting

### Проблема: Иконка не появляется в статус-баре
**Решение:**
1. Проверьте, запущено ли приложение: `ps aux | grep MCCPortForwarder`
2. Перезапустите приложение
3. Проверьте права доступа в System Settings → Privacy & Security

### Проблема: Ошибка "command not found"
**Решение:**
1. Проверьте установку CLI: `which mcc`
2. Если не установлен, установите или измените команду в настройках
3. Убедитесь, что путь правильный: `/usr/local/bin/mcc` или `/opt/homebrew/bin/mcc`

### Проблема: Порт уже занят
**Решение:**
1. Проверьте, не запущен ли процесс уже: `lsof -i :PORT`
2. Остановите конфликтующий процесс
3. Попробуйте другой локальный порт

### Проблема: Приложение зависло
**Решение:**
```bash
killall MCCPortForwarder
open /Applications/MCCPortForwarder.app
```

## Поддержка

3. Попробуйте остановить и запустить заново
4. Проверьте версию macOS (требуется 13.0+)
